# 💬 TarGPT — Chat, but Make It Awesome  

> **TarGPT** is your stylish AI chat companion built using **Google Gemini API**.  
> It’s fast, beautiful, and has that extra sparkle ✨ — like GPT, but with *way* better vibes.

## 🧠 About the Project  

TarGPT gives you an **awesome chat experience** without the typical dull chatbot feel.  
It’s built for developers who love clean design, smooth animations, and modern UI — all powered by Google’s Gemini intelligence.  

🟢 Minimal setup.  
🎨 Stunning visuals.  
⚡ Blazingly fast responses.

## 🪄 How to Run Locally  

Clone and run the project right on your machine 🧑‍💻  

```bash
# Clone the repo
git clone https://github.com/<your-username>/TarGPT.git

# Move into project folder
cd TarGPT

# Open index.html in your browser
```

That’s it! 🎉  
No build steps, no frameworks — just clean **HTML, CSS, and JS**.

---

## 🔑 Setting Up Gemini API  

1. Go to [Google AI Studio](https://makersuite.google.com/app/apikey)  
2. Generate your **Gemini API key**  
3. In your code, replace this line:  

```js
const GEMINI_API_KEY = "YOUR_API_KEY_HERE";
```

4. Save and refresh — TarGPT will start chatting smartly 🤖
